# Beyond Baby Names Android 1.1.0

- `BeyondBabyNames-1.1.0-debug.apk` is signed with a local Android debug
  certificate and can be installed on a test device.
- `BeyondBabyNames-1.1.0-unsigned.apk` is the optimized release APK.
- `BeyondBabyNames-1.1.0-unsigned.aab` is the optimized Play bundle.

The release APK and AAB are intentionally unsigned. Sign them with the
project's protected production upload key before distribution or Play upload.
