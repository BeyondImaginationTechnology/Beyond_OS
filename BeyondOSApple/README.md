# Beyond OS iOS 0.1

A native iOS companion for Beyond OS—not a replacement operating system and not dependent on jailbreak access. It provides a secure handoff to Beyond ID, Beyond OS Web, and Beyond Studio.

Generate the Xcode project with:

```sh
xcodegen generate --spec BeyondOSApple/project.yml
```

Optional enthusiast jailbreak customization, if ever pursued, must remain a separate project with its own security review and distribution policy. It is not a dependency of this app.
