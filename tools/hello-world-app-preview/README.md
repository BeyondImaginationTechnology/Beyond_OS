# Hello World App Preview

An 8-second vertical App Store-style preview built with Remotion.

```bash
npm install
npm run studio
npm run render
```

The rendered video is written to `out/hello-world-app-preview.mp4`.

## Beyond French daily lesson generator

Prepare any lesson from `beyond-french/data/lessons.json`, preview it, and render:

```bash
npm run prepare:beyond-french -- 2
npm run still:beyond-french
npm run render:beyond-french
```

The hosted Daily Studio uses Remotion's browser renderer so a PHP-only server
does not need Node, Chromium, or FFmpeg. Rebuild its committed browser bundle
after changing the Beyond French composition:

```bash
npm run build:beyond-french-browser
```

The bundle is written to
`server/admin/daily-studio/assets/beyond-french-remotion-renderer.js`.

To attach an MP3 that was generated by the Beyond French Narration Studio:

```bash
BEYOND_FRENCH_LESSON_ID=2 \
BEYOND_FRENCH_AUDIO_FILE=/absolute/path/to/narration.mp3 \
npm run prepare:beyond-french
```

For a deployed site, the public `beyond-french/api/video-config.php` endpoint
returns the daily lesson fields and its latest published English video
voiceover. The preparation script can download both:

```bash
BEYOND_FRENCH_CONFIG_URL="https://example.com/beyond-french/api/video-config.php?lesson_id=2" \
npm run prepare:beyond-french
```

API credentials stay in the private PHP/server configuration and are never
written into Remotion props or public files.
