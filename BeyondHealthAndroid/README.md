# Beyond Health Android v0.0.1

Native, offline Android companion for API 26 and later.

Open this folder in Android Studio and build the `app` module. The app uses the standard Android SDK and no third-party libraries. It has Today, Journal, Practices, Insights, and Settings. Check-ins and journal notes are stored in private app preferences. Android backup and network access are disabled for this first release.

This release does not sync with the web app or iOS.
