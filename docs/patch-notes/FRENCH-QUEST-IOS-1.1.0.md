# French Quest iOS 1.1.0

Initial native SwiftUI game build.

## Includes

- New `FrenchQuestApple` iOS app with `FrenchQuest.xcodeproj`.
- Three launch regions: Bonjour Bay, Cafe Crossing, and Metro Maze.
- Nine playable French challenges with answer choices, tips, pronunciation, and local speech playback.
- Quest map, phrasebook, training room, hero profile, XP, hearts, streaks, and local progress persistence.
- Version metadata set to marketing version 1.1.0, build 1.

## Notes

The app uses generated launch screen metadata instead of a storyboard so the project can avoid local Interface Builder platform issues during command-line builds.
