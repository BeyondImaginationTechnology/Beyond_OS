# Beyond TV 1.1.0

Release date: 2026-08-28

## Web

- Keeps all web channels free and available without an account.
- Adds the Beyond Supporter promotion with a 365-day iOS trial and approved weekly, monthly, and annual pricing.
- Marks Android as coming soon.
- Adds installable web-app metadata, scoped static-asset caching, and a machine-readable release manifest.

## Apple platforms

- Updates iOS, iPadOS, and tvOS to version 1.1.0 (build 110).
- Secures Beyond ID tokens with Keychain and bearer authentication.
- Prevents unapproved catalog candidates and unresolved collections from playing.
- Opens selected Browse titles in the Watch tab.
- Fixes Vancouver guide timing and light-theme appearance.
- Adds a privacy manifest and membership information to the Account view.

## Android

- Introduces the `BeyondTVAndroid` native project at version 1.1.0 (110).
- Provides a secure WebView shell for the canonical Beyond TV web app.
- Adds verified-domain deep links, media playback, cookie-based Beyond ID sessions, external-link isolation, and offline retry behavior.
- Uses HTTPS-only networking and does not include signing secrets.

## Membership status

The membership presentation is informational in 1.1.0. Checkout, recurring billing, trial activation dates, and server-side entitlements are not enabled until a payment provider and membership API are implemented.
