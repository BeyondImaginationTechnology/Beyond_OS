# Beyond Space for Android

Native Android v0.1 starter for the shared Beyond Space daily-fact and Academy experience.

## Open and run

Open this folder in Android Studio and select the `app` run configuration. The app uses the same public daily-fact API as the web experience and iOS app, keeps saved facts on the device, and opens the related Academy lesson, Beyond Space TV channel, and YouTube playlist in the browser.

The project targets Android 8.0 (API 26) and uses the Android SDK and Gradle versions already used by the Beyond Imagination Android projects.
