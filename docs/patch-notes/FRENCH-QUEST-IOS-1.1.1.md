# French Quest iOS 1.1.1

Production content and offline voice update.

## Includes

- Promotes French Quest from the local beta to marketing version 1.1.1, build 2.
- Expands the phrasebook from 58 to 158 practical entries.
- Adds 100 daily lessons across greetings, conversation, travel, food, shopping, everyday language, and encouragement.
- Bundles Azure Speech neural French recordings for the 100 new entries.
- Provides offline French playback for all 158 phrasebook entries, with on-device speech as a fallback.
- Adds prerecorded French playback to the matching web lessons and dictionary entries.
- Replaces the five-tab learning-app shell with a game-first adventure hub, realm map, spellbook, training grounds, and hero lodge.
- Uses the new FrenchQuest artwork in the in-game header and adds mission rewards, realm states, and game-style answer controls.
- Adds a looping French accordion soundtrack by BFCMUSIC with a persistent in-game music toggle.
- Replaces beta-only wording with release-ready copy.

## Voice generation

The new recordings were generated from the Azure Speech API with the Canadian French neural voice and copied into the app bundle. Azure credentials are read from environment variables and are not stored in the project.
