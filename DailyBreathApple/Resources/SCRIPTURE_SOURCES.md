# Scripture sources

The Daily Breath keeps these editions offline and identifies translations as meanings/translations rather than as replacements for the original sacred text.

- English Bible and English Torah/Tanakh translation: World English Bible, public domain (`engwebp_vpl.txt`).
- French Bible and French Torah/Tanakh translation: Louis Segond 1910, public domain, distributed by eBible.org (`fraLSG_vpl.txt`).
- Spanish Bible: Reina-Valera 1909, public domain, distributed by eBible.org (`spaRV1909_vpl.txt`).
- Hebrew Torah/Tanakh: Modern Hebrew Bible, public domain, distributed by eBible.org (`heb_vpl.txt`). Only the Hebrew Scriptures are presented in the Torah/Tanakh reader.
- Arabic Quran: Quran JSON 3.1.2 by Risan Bagja Pradana, CC BY-SA 4.0 (`quran-ar.json`). Its Uthmani Arabic text is sourced from the Noble Qur'an Encyclopedia. See `QURAN_JSON_LICENSE.txt`.
- English Quran meaning: Mohammed Marmaduke Pickthall (`quran-pickthall-vpl.txt`).
