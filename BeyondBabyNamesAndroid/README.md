# Beyond Baby Names 1.1 for Android

Native, private, offline baby-name discovery for Android.

## Features

- Browse names with origins, meanings, and vibes.
- Swipe with Pass, Maybe, and Love decisions.
- Save a private on-device shortlist.
- Preview favorites with a family name, initials, and name-flow guidance.
- Explore a private demo Couple Mode.

The application ID is `technology.co.beyondimagination.beyondbabynames`.

## Build

```powershell
.\gradlew.bat :app:assembleRelease
```
