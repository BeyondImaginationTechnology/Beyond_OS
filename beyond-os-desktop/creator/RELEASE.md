# Creator 0.1 release gates

Creator 0.1 remains a development preview until all of these are complete:

- Creator Hub compiles with warnings treated as errors.
- Workspace, app, automatic-start, playlist, and wallpaper choices persist.
- Creator project folders are created with the desktop user's ownership.
- Optional app cards clearly distinguish available and planned packages.
- Installer media is built, checksum verified, and booted with UEFI.
- A clean install reaches Creator Hub and does not identify itself as Core.
- Music playback, wallpaper rendering, keyboard navigation, and scaled-display
  behavior are checked in the shipping image.
