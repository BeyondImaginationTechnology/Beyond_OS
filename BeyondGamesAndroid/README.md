# Beyond Games for Android

Native, offline Android arcade collection for the five games marked **Playable prototype** in the shared catalog:

- Bit Runner — three-lane touch dodge runner
- Beyond Hoop — timing-based shooting rush
- Zak’s Kitchen Rush — recipe-step management
- Tattoo Master — steady-hand stencil tracing
- French Quest — French dialogue challenge

The remaining catalog entries are intentionally visible only on the web roadmap because their source manifest identifies them as concepts, pre-production, or design-phase games. They should not be marketed as playable Android releases yet.

Open in Android Studio, install API 37, then build an APK or signed Android App Bundle. The app uses Java 17 and Android Gradle Plugin 9.3.0 with no third-party runtime dependencies.
