# DailyBreath character turnaround handoff

The `tripo-multiview` subfolders contain one PNG per slot in Tripo's four-view HD Model input. Upload all four files from **one** character folder in a single generation:

| Tripo slot | File |
| --- | --- |
| Front | `front.png` |
| Left | `left.png` (face points to image right) |
| Right | `right.png` (face points to image left) |
| Back | `back.png` |

The `dovi-tripo-turnaround-v1.png` and `moe-tripo-turnaround-v1.png` files are overview/reference sheets, not four-view uploads. The individual files were generated from those sheets for consistent identity, wardrobe, and framing. Inspect Tripo's preview before committing to a final mesh: generative views can vary subtly in hair, buttons, or proportions.

Dovi: white collared shirt, navy cardigan, charcoal trousers, brown shoes. Moe: off-white band-collar shirt, plum cardigan, charcoal trousers, brown shoes. Both are adult-proportioned, neutral A-pose characters with no book or other prop baked into the model.
