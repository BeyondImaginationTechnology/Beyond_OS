Provider sign-in artwork

- `github-invertocat-white.png` is the white GitHub Invertocat from GitHub's official logo package: https://brand.github.com/GitHub_Logos.zip. `login.php` embeds it inline to avoid separate asset requests. Use it only to identify GitHub sign-in and follow GitHub's logo policy: https://brand.github.com/foundations/logo. This is not a blanket commercial license for other uses.
- `apple-continue-button.png` is Apple's generated “Continue with Apple” artwork from its official endpoint: https://appleid.cdn-apple.com/appleid/button/left. `login.php` embeds it inline. Follow Apple's Sign in with Apple design guidance: https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple.
